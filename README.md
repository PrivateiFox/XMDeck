# XMDeck

**XMDeck** is an open-source Decky Loader plugin for SteamOS that allows users to monitor and control Sony WH/WF-1000XM headphones directly from the Steam Quick Access Menu (QAM).

## Features
- **Battery Status:** Monitor battery percentage and charging state for both headphones and earbuds.
- **Active Noise Cancellation (ANC):** Seamlessly switch between Noise Cancelling, Ambient Sound, and Off.
- **Ambient Sound Level:** Adjust ambient sound transparency (1–20) with live feedback.
- **Voice Focus:** Toggle voice enhancement in ambient sound mode.
- **Speak-to-Chat:** Toggle Sony's automatic speech detection.
- **Hardware Button Sync:** Reactive state updates when settings change via physical buttons.

## Requirements
- SteamOS / Linux with BlueZ
- Sony WH/WF-1000XM series headphones (WH-1000XM3/XM4/XM5, WF-1000XM3/XM4/XM5, LinkBuds)
